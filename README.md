# Ian Watkins — WhoDatedWho Comments (Dated, Censored Archive)

A reconstructed, dated archive of the public comments left on Ian Watkins' WhoDatedWho
profile before his arrest on 19 December 2012, together with the immediate reactions in
the days that followed.

> **Content warning:** this material discusses CSA.

## What this is

The original page showed only a relative age for each comment ("2 yrs ago"). This version:

- replaces each with an **approximate real date**, reconstructed by comparing many archived
  snapshots of the page — **hover any date** to see the exact readings it was built from;
- recovers comments that were later **deleted** from the live site;
- collapses duplicates.

**1,503 comments** in total — **1,428** posted before the arrest and **75** in the four days
after, at which point the thread was frozen to new comments.

## Viewing

Open `index.html` in any browser. It is a single, self-contained file — no internet
connection required.

## Features

- **Highlights** — comments discussing his crimes, immediate post-arrest reactions, and
  deleted comments are each marked in a distinct style.
- **Filters** — show only crime-related, post-arrest, or deleted comments, or comments about
  specific people.
- **Date evidence** — every reconstructed date carries a tooltip listing the archived
  readings behind it and how confident the estimate is.

## Censorship

This is the **censored** copy, intended for public reference. To protect victims:

- identifying names are replaced with neutral labels (hover them for context);
- any child is fully redacted with a solid black bar, along with any wording that would
  identify a child by family relationship.

Notably, a child victim's name — and the identity of one of the women later convicted
alongside Watkins — were posted publicly in this thread **more than a year before his
arrest**.

## Accuracy & limitations

- Dates are **estimates**, each with a stated confidence level; check the tooltip.
- The very start of the thread (likely several dozen comments) predates the first usable
  archives and could not be recovered.
- Comment text is reproduced verbatim from archived snapshots.
